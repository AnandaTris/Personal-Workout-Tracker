#Personal Workout App
##Workout App(personal)
Simple app I built for my self to remember the working sets and workouts in the gym as well as keep track of the weights for progressive overload
##How it's used 
Just put all fo your days into the app and then put the names of the workout in. Keep track of your sets and reps alongside with the weights that you can do.
##Tech Stack Used                   
  Runtime & Build                                                               
  - Node.js - JavaScript runtime                                                
  - Vite 7 - build tool and dev server                                          
                                         
  Frontend                                                                      
  - React 19 - UI framework
  - JSX - component syntax                                                      
  - Plain CSS (per-component files) - styling, no CSS framework
                                                                                
  PWA                                                                           
  - vite-plugin-pwa - service worker + web manifest generation                  
  - Workbox - offline caching (auto-generated by vite-plugin-pwa)               
                                         
  Storage                                                                       
  - localStorage - all data persistence, no backend
                                                                                
  Dev Tools                              
  - sharp - icon generation (PNG from SVG, one-time script)                     
  - ESLint - linting                                                            
   
  Deployment                                                                    
  - Vercel - hosting
